# 42 Cyber Piscine Bootcamp Projects

This repository contains a collection of cybersecurity projects completed during the 42 School Cyber Piscine bootcamp. These projects cover fundamental concepts in cybersecurity, from defensive mechanisms to ethical hacking techniques and cryptography.

## 🛡️ Projects Overview

### **Anashida Project**
A comprehensive cybersecurity project focusing on advanced security concepts and implementations. This project demonstrates proficiency in security analysis and protective measures.

### **Iron Dome Malware**
Implementation of defensive cybersecurity mechanisms inspired by the Iron Dome defense system. This project focuses on:
- Malware detection and prevention
- Real-time threat analysis
- Automated defense responses
- Security monitoring systems

### **Vaccine SQL Injection**
A project dedicated to understanding and preventing SQL injection attacks. Key learning objectives include:
- Identifying SQL injection vulnerabilities
- Implementing input validation and sanitization
- Creating secure database queries
- Developing protective "vaccines" against common injection techniques

### **ft_onion**
Deep web and anonymity project exploring:
- Tor network implementation
- Onion routing protocols
- Anonymous communication systems
- Privacy and security in network communications

### **ft_otp**
One-Time Password (OTP) implementation project covering:
- Time-based OTP (TOTP) algorithms
- Multi-factor authentication systems
- Cryptographic security for authentication
- RFC compliance for OTP standards

### **Inquisitor**
Network reconnaissance and information gathering project focusing on:
- Network scanning techniques
- Information enumeration
- Ethical reconnaissance methodologies
- Security assessment tools

### **Reverse Me**
Reverse engineering project that develops skills in:
- Binary analysis and disassembly
- Code deobfuscation techniques
- Malware analysis fundamentals
- Understanding program execution flow

### **Stockholm Malware**
Educational malware project (for learning purposes) that explores:
- Malware behavior analysis
- Encryption and file manipulation
- System security vulnerabilities
- Ethical malware research methodologies

## 🎯 Learning Objectives

Through these projects, key cybersecurity competencies are developed:

- **Defensive Security**: Understanding how to protect systems and data
- **Offensive Security**: Learning ethical hacking techniques for security testing
- **Cryptography**: Implementing secure communication and authentication
- **Network Security**: Analyzing and securing network communications
- **Malware Analysis**: Understanding and defending against malicious software
- **Web Security**: Preventing common web application vulnerabilities
